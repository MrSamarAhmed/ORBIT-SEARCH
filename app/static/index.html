ORBIT Search

An AI research agent that turns live web search into structured, source-grounded research.

API docs Health

Ask a research question

ORBIT plans sub-questions, searches the live web, and writes a structured answer grounded only in the sources it actually retrieved.

Can take up to a minute — searching and reading sources takes time.

Try:

From question to cited answer

  1. 1

    Question

    You ask one natural-language question.

  2. 2

    Plan

    An LLM planner breaks it into focused search queries.

  3. 3

    Search

    Each query runs against the live web via SerpApi.

  4. 4

    Evidence

    Results are deduplicated and the strongest sources are kept.

  5. 5

    Synthesis

    An LLM writes the answer using only the collected evidence.

  6. 6

    Citations

    Inline citation links are checked against the retrieved sources.

Honest by design: if synthesis is unavailable, you still get the planned queries and the real sources retrieved — never a fabricated answer.
