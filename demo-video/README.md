# Demo video production

`render/` holds the three scripts that produced the hackathon submission video.
Only the scripts and their text inputs are versioned; every generated media
file is gitignored (see the `demo-video` block in the root `.gitignore`).

## What is and is not in Git

| Path | Tracked | Why |
|---|---|---|
| `render/make_frames.py` | yes | generates the code/tree/test/credit HTML pages |
| `render/make_narration.py` | yes | generates the narration WAV clips and `captions/timeline.json` |
| `render/make_video.py` | yes | crops/scales frames, builds clips, narration, music, subtitles, final MP4 |
| `assets/tree.txt` | yes | input rendered by the repository-layout frame |
| `assets/pytest_output.txt` | yes | input rendered by the test-suite terminal frame |
| `ORBIT_Search_SerpApi_Hackathon_Demo.mp4` | no | the rendered deliverable (26 MB) |
| `audio/`, `build/`, `frames/`, `captions/`, `render/html/` | no | generated intermediates |
| `bin/ffmpeg` | no | local symlink whose target contains an absolute machine path |
| `assets/s4_success_dump.txt` | no | captured live API response body |

## External dependencies

The scripts do not download anything and expect two tools that are **not** in
this repository:

- **FFmpeg** — `make_narration.py` and `make_video.py` call
  `demo-video/bin/ffmpeg`. Create that path yourself, for example:

  ```bash
  mkdir -p demo-video/bin
  ln -s "$(python -c 'import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())')" \
        demo-video/bin/ffmpeg
  # or simply: ln -s "$(command -v ffmpeg)" demo-video/bin/ffmpeg
  ```

- **Google Chrome** (or any headless Chromium) — `make_frames.py` only writes
  HTML; the HTML → 1920×1080 PNG step is a manual command:

  ```bash
  "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
    --headless=new --disable-gpu --hide-scrollbars --no-sandbox \
    --force-device-scale-factor=1 --window-size=1920,1080 \
    --screenshot=demo-video/frames/R_<name>.png \
    "file://$PWD/demo-video/render/html/<name>.html"
  ```

- **macOS `say`** — `make_narration.py` uses the local `say` command (Samantha,
  172 wpm). On other platforms substitute any TTS that writes an audio file.

## Regenerating

```bash
python demo-video/render/make_frames.py            # -> render/html/*.html
# screenshot each HTML with headless Chrome -> frames/R_*.png
python demo-video/render/make_narration.py         # -> audio/*.wav + captions/timeline.json
python demo-video/render/make_video.py             # -> ORBIT_Search_SerpApi_Hackathon_Demo.mp4
```

`make_video.py` reads the app screenshots from `frames/` too. Those are genuine
captures of the running application (one successful Gemini run and one genuine
429 degraded run); they cannot be regenerated by a script, and re-recording
them costs live SerpApi and Gemini requests.

## Notes on the captured inputs

- `assets/pytest_output.txt` is the verbatim output of the focused suite
  (`56 passed, 8 skipped, 1 warning in 0.11s`) with one edit: the absolute
  working-directory prefix on the deprecation notice was rewritten as a
  relative path. The frame script already prints only the progress line and the
  summary line.
- `assets/tree.txt` is `git ls-files` for the repository at the time of the
  video.
- `make_frames.py` hard-codes the summary string it colourises; if you re-run
  the suite and the counts change, update both that literal and the asset.

## Known limitations

- The repository-layout frame is authored for 24 tree lines at `27px/1.62`. A
  listing longer than that overflows the 1080 px viewport and `body` clips it,
  so the final line(s) and the caption note are cut off — this is visible in
  the shipped video, where `tests/test_search.py` is truncated at the bottom
  edge. Every line that does appear is accurate. Reduce `.tree` font-size or
  split the listing if you re-render.
- The app screenshots in `frames/` are 1034 px-wide browser captures upscaled
  into the 1920×1080 timeline, so UI shots are softer than the natively
  rendered code and card frames.
- Narration uses the stock macOS `say` Samantha voice; the music bed is a
  synthesised low-level sine pad, not a licensed track.
